# METRO — Вкус начинается здесь

Независимый интерактивный дизайн-концепт для магазина по адресу Москва, ул. Маршала Прошлякова, 14. Не официальный сайт METRO. Визуальное направление основано на предоставленных скриншотах; видеоролики Instagram не были проверены. Использованы два фото магазина из брифа и две AI-визуализации: фасад по референсам и вымышленный интерьер. Они явно помечены на сайте. Схема адреса декоративная, точный маршрут открывается в Яндекс Картах.

## Запуск

Node.js 22.12+ или 24.

```bash
npm ci
npm run dev
```

Открыть адрес, показанный Vite. Сборка: `npm run build`. Проверка сборки: `npm run preview`.

## Что работает

Три процедурные WebGL-сцены Three.js, реакция на курсор и прокрутку, переключение композиции, остановка движения, поддержка prefers-reduced-motion, рецепты в диалоге с копированием, раскрывающиеся советы, внешние ссылки на карту и официальный сайт. Мобильная компоновка. Рецепты иллюстративные, продажи, актуальные остатки и оплата не подключены. Изображения карточек — системные emoji; главный экран — настоящая 3D-геометрия, а не фотореалистичный рекламный рендер. Шрифт Golos загружается из Google Fonts, с локальным системным запасным вариантом.

## GitHub Pages

Создайте пустой репозиторий в своём GitHub, добавьте remote и отправьте ветку main. В Settings → Pages выберите Source: GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует dist. Сборка использует относительные пути и работает в подпапке репозитория. Проект сохранён как локальный Git-репозиторий; удалённый репозиторий не создавался.

## Как довести до рекламного качества

1. В Blender подготовить фотореалистичные модели пасты, вилки, ягод и жидкости. Для жидкости — симуляция Mantaflow, запечённая в GLB-анимацию или видео с прозрачностью. Уточнить права на брендовые материалы.
2. Экспортировать GLB с Meshopt/Draco и KTX2-текстурами; целевой бюджет первого экрана до 5 МБ, мобильной версии до 2 МБ. Заменить процедурные группы в src/main.js через GLTFLoader.
3. Добавить GSAP ScrollTrigger для управляемого прокруткой распада композиции между секциями; обеспечить статичный кадр при reduced-motion и отсутствии WebGL.
4. Заменить emoji в карточках на согласованные студийные рендеры; добавить подтверждённые фото магазина и часы работы.
5. Для полноценного магазина подключить согласованный API каталога, цен и остатков, серверную корзину, оплату, CMS рецептов. Не хранить секреты в браузере. Эти функции требуют доступа к системам магазина и отдельного проектирования.

## Структура

`index.html` — страницы и диалог. `src/style.css` — адаптивный дизайн. `src/main.js` — сцены и интерактивность. `dist/` — результат сборки.


## STROGINO EDITION

Добавлена архитектурная вступительная сцена с приближением к входу при нативной прокрутке и переходом к интерьерной концепции. Это кинематографический 2D-переход, не точная 3D-реконструкция здания. Для настоящего прохода через двери потребуется фотограмметрия/модель фасада и согласованный интерьер. Существующие 3D-сцены и рецепты сохранены.

## Проверка

Production-сборка успешна. В Chromium проверены переключение 3D-сцены, рецепты, советы, фильтрация журнала, открытие статей, подборки, эффект прокрутки. ## Immersive Edition — Three.js

Основная новая сцена `#immersion` — отдельный realtime WebGL-мир в `src/experience.js`:

- камера приближается по мере прокрутки трёх глав; ингредиенты расходятся и собираются;
- семь световых колец, shader-частицы (до 1500 на компьютере / 550 на сенсорных устройствах), shader-сетка пола;
- постобработка EffectComposer → RenderPass → UnrealBloomPass → OutputPass;
- объёмные томаты, листья, паста, тарелка, 80 частиц приправы через InstancedMesh;
- вращение перетаскиванием/касанием, стрелками клавиатуры и возврат через Home;
- режимы «Авто», «Кино», «Лёгкий», интенсивность и общая остановка движения;
- автоадаптация разрешения при длительных медленных кадрах, ограничение DPR на телефоне, остановка отрисовки невидимых сцен и фоновой вкладки;
- поддержка prefers-reduced-motion при загрузке и при изменении настройки системы;
- нативная вертикальная прокрутка, без scroll hijacking, touch-action: pan-y.

Существующая продуктовая сцена дополнена частицами, орбитой, плавным появлением при смене композиции и разлётом ингредиентов по нажатию. На странице: вступление текста по строкам, последовательное появление разделов, световые блики, наклоны карточек на устройствах с мышью, параллакс интерьерного фона, общий индикатор прокрутки.

Модели процедурные, стилизованные. Это интерактивная графика, не фотореалистичный рекламный рендер. Режим «Кино» увеличивает GPU-нагрузку; частота кадров на реальных устройствах не измерялась. Автоматические проверки проводились в Chromium с программным WebGL, включая сенсорный viewport 390×844. Не подменять этим проверку на физических iPhone/Android.

Проверено: два WebGL canvas, смена глав, качество, пауза, reduced-motion, открытие рецептов, отсутствие горизонтального переполнения и ошибок загрузки в мобильном сценарии. Production-сборка проходит. Vite предупреждает о размере основного JS (~595 КБ до gzip, ~153 КБ gzip); дополнительная сцена загружается отдельным модулем (~10 КБ gzip).
