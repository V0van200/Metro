# METRO · Winter Edition 2027

Независимая новогодняя витрина для METRO в Строгино, ул. Маршала Прошлякова, 14. Не официальный сайт METRO. Оплата и оформление заказов отсутствуют.

## Открыть

https://v0van200.github.io/Metro/

Исходный код в main: https://github.com/V0van200/Metro . Готовая сборка публикуется из ветки gh-pages, папка / (root). Не переключайте Pages на Actions: этот репозиторий использует публикацию из ветки. Пример альтернативного workflow сохранён в docs, но не активен.

## Локальный запуск

Node.js 22.12+ или 24:

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## Что добавлено

- 24 карточки праздничных товаров из опубликованных страниц METRO: 6 категорий, поиск, фильтры, сортировка по названию.
- Диалог товара, прямая ссылка на товар или содержащую его категорию официального каталога, список желаний в localStorage, удаление и копирование списка.
- Новый экран Three.js: процедурная ёлка с инстансированными иголками, украшения, огоньки, подарки, Дед Мороз в длинной шубе, снег. Вращение касанием/перетаскиванием и кнопкой; выключение огоньков.
- Прикреплённые к верхней планке подвесные шары. Пружинное движение от скорости прокрутки с затуханием. Уменьшаются над каталогом и не блокируют касания.
- Пауза движения, prefers-reduced-motion, ограниченный DPR, остановка рендера вне экрана и скрытой вкладки.

## Источники и изображения

Поиск 21–22 октября 2026 года. Названия и размеры взяты из результатов официального каталога online.metro-cc.ru. У каждой карточки своя ссылка на страницу товара или категорию, где товар был найден; они перечислены в src/holiday.js. Текущие цены и наличие конкретного филиала не подтверждены, поэтому не показаны. Описания — короткие авторские рекомендации, не скопированные рекламные тексты.

Изображение public/images/holiday-collection.png создано генератором изображений как шесть согласованных иллюстраций категорий. Оно не изображает точные товарные модели; это явно указано на странице и в диалоге товара. CSS выбирает нужный сегмент. Точные фотографии следует смотреть на странице продавца. Предоставленные пользователем фотографии послужили референсом праздничного отдела, но не выдаются за новые студийные снимки.

Основные источники: https://online.metro-cc.ru/products/el-tarrington-house-nadleen-180-sm ; https://online.metro-cc.ru/products/figura-ded-moroz-40-sm-v-assortimente ; https://online.metro-cc.ru/category/tovary-dlya-doma-dachi-sada/novogodnie-tovary-ny . Все 24 ссылки находятся в данных каталога.

index.html, src/holiday.js, src/holiday.css — активная новогодняя версия. Старые main.js, experience.js, style.css оставлены как исходники предыдущего концепта и не подключаются. История изменений сохранена в Git.

## Проверка

Production-сборка, Chromium: 24 карточки, поиск (2 результата Nadleen), фильтр гирлянд (5), пустая выдача и сброс, диалог, сохранение избранного после перезагрузки, управление огоньками и пауза. На ширине 390 px горизонтального переполнения нет. Ошибок JavaScript не обнаружено. Результат WebGL проверен программным Chromium; реальная частота кадров на телефонах не измерялась.

## Обновление: конструктор и справочник

Добавлены: три палитры (классика, золото, хвойная), три пространства, динамическая подборка из четырёх существующих карточек, добавление всей подборки в список, изменение цвета украшений в Three.js, анимированная композиция подвесных шаров. Подборка редакционная и не является комплектом продавца.

Информационные разделы: METRO Chef, RIOBA, METRO Professional со ссылкой https://metro-cc.ru/our-brands ; FAQ с официальными правилами https://metro-cc.ru/visiting-rules и оформлением карты https://metro-cc.ru/cards . Проверено 22.10.2026: карта не обязательна для личных покупок, но требуется для программ лояльности, специальных условий и профессиональных покупок. Не обещаются скидки или наличие.

Главная официального сайта не загрузилась в браузере (таймаут). Структура меню и сведения исследованы через доступную официальную страницу правил и индексируемые страницы брендов. Полное визуальное сравнение с главной не выполнено.

Мобильная нижняя навигация: каталог, подборка, список, магазин. Дополнительно — появление редакционных разделов при прокрутке, индикатор прогресса, анимированные переходы между брендами и FAQ. Учитываются пауза и reduced-motion.

## Обычная главная → сезонная коллекция

Первым показывается сине-жёлтый экран METRO с магазином и адресом, далее — информация о посещении, четыре направления каталога и марки сети. Затем отдельный переход в новогоднюю коллекцию. Главная — #home, новогодняя сцена — #winter. Подвесные шары появляются только при приближении к новогоднему разделу и скрываются при возврате к обычной главной. Палитра конструктора ведёт к #winter. Основные функции праздничного каталога сохранены. Изображение фасада — ранее созданная художественная визуализация, подпись сохранена.
